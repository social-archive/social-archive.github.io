# 리서치 대시보드

Mode: Operate / Read.

Confirmed direction: 기존 SOS Admin UI 재사용. 첫 화면은 주제 탐색, 순위 목록, 브리핑 상세로 구성한다. GitHub Pages에는 화면 코드만 제공하고 데이터는 공개 발행 전용 API에서 읽는다. 소셜 로그인은 보관만 하고 현재 화면에서는 사용하지 않는다. 실제 데이터가 없으면 발행 대기 상태로 표시한다.

First viewport: 회색 사이드바, 전체 리서치 제목, 검색/순위 목록, 선택 항목의 상세 영역. 모바일에서는 주제 가로 탐색과 목록/상세 전환을 제공한다.
